# DSA Day 49 - Recursion 

## Topics Covered
- Power of a number using recursion
- Sum of digits using recursion
- Count digits using recursion
- Sum of array elements using recursion
- Find maximum element in an array using recursion

## Key Concepts
- Base case stops recursive calls.
- Recursive case reduces the problem size.
- Integer division (//) removes the last digit.
- Modulo (%) extracts the last digit.
- Arrays can be processed recursively using their size or index.


## Complexity
- Power: O(n) time, O(n) stack space
- Sum of digits: O(d) time, O(d) stack space
- Count digits: O(d) time, O(d) stack space
- Sum of array: O(n) time, O(n) stack space
- Maximum in array: O(n) time, O(n) stack space

Here, n is the exponent or array size, and d is the
number of digits.
