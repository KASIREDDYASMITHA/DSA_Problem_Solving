
# DSA Day 48 - Recursion 3

## Topics Covered
- Recursion and base cases
- Backtracking
- Factorial of a number using recursion
- Recursion time complexity
- Back substitution method
- Binary search using recursion
- Power of a number using recursion
- Sum of digits
- Count digits
- Sum of array elements


## Key Concepts
- A base case stops recursive calls.
- A recursive case reduces the problem into a smaller problem.
- Back substitution expands a recurrence until its base case.
- Recursive binary search works on a sorted array.
- Backtracking explores a choice and then reverses that choice when needed.
