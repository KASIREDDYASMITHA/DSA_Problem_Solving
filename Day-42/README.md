# Day 42 – Linked List 

## Topics Covered
- Finding the middle node of a linked list using the slow and fast pointer technique.
- Detecting a cycle in a linked list using Floyd's Cycle Detection Algorithm.

## Key Concepts
- **Slow Pointer:** Moves one node at a time.
- **Fast Pointer:** Moves two nodes at a time.
- **Cycle Detection:** If both pointers meet, a cycle exists.

## Complexity
- Finding the middle node: O(n) time, O(1) auxiliary space.
- Detecting a cycle: O(n) time, O(1) auxiliary space.
