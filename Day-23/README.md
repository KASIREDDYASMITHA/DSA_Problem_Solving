# DSA Day 23

## Topics Covered

### 1. Product of Array Except Self
- Brute Force Approach
- Prefix + Suffix Product Approach
- Optimized Prefix + Suffix Approach

### 2. Run-Length Encoding
- Count consecutive repeated characters
- Generate encoded string using character + count

### 3. Sort Colors
- Sort an array containing only 0, 1 and 2
- Counting Approach

## Approaches

| Problem | Approach | Time Complexity | Space Complexity |
|---|---|---:|---:|
| Product of Array Except Self | Brute Force | O(n²) | O(n) |
| Product of Array Except Self | Prefix + Suffix | O(n) | O(n) |
| Product of Array Except Self | Optimized Prefix + Suffix | O(n) | O(1) auxiliary |
| Run-Length Encoding | Consecutive Counting | O(n) | O(n) |
| Sort Colors | Counting | O(n) | O(1) |

## Key Learning

- Brute force can be improved using prefix and suffix products.
- Prefix and suffix products can be combined to solve the problem in O(n).
- The optimized approach avoids separate left and right arrays.
- Run-Length Encoding uses consecutive character counting.
- Sort Colors can be solved by counting the number of 0s, 1s and 2s.
