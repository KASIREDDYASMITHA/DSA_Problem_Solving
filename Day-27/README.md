## Key Learning

A stack follows the LIFO (Last In, First Out) principle.

Stacks are useful when:
- We need to process the most recently added element first.
- We need to match opening and closing brackets.
- We need to keep track of previous elements.

## Complexity

### Valid Parentheses
- Time Complexity: O(n)
- Space Complexity: O(n)

### Stock Span - Brute Force
- Time Complexity: O(n²)
- Space Complexity: O(n)
