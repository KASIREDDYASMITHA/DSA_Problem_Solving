# Day 01 - Pseudocode

## 1. Calculate Area of Rectangle

1. Start
2. Read length and breadth
3. Calculate area = length × breadth
4. Print area
5. Stop


## 2. Even or Odd

1. Start
2. Read N
3. Check whether N mod 2 equals 0
4. If yes, print "Even"
5. Otherwise, print "Odd"
6. Stop


## 3. Positive, Negative or Zero

1. Start
2. Read N
3. If N > 0, print "P"
4. Else if N < 0, print "N"
5. Otherwise, print "Z"
6. Stop


## 4. Largest of Three Numbers

1. Start
2. Read A, B and C
3. If A > B and A > C, print A
4. Else if B > C, print B
5. Otherwise, print C
6. Stop


## 5. Leap Year

1. Start
2. Read year
3. If year mod 400 equals 0, print "Leap Year"
4. Else if year mod 100 equals 0, print "Not a Leap Year"
5. Else if year mod 4 equals 0, print "Leap Year"
6. Otherwise, print "Not a Leap Year"
7. Stop


## 6. Grading

1. Start
2. Read marks
3. If marks >= 90, print "A"
4. Else if marks >= 75, print "B"
5. Else if marks >= 60, print "C"
6. Else if marks >= 40, print "D"
7. Otherwise, print "F"
8. Stop


## 7. Fizz Buzz

1. Start
2. Read N
3. If N mod 15 equals 0, print "FB"
4. Else if N mod 3 equals 0, print "FZ"
5. Else if N mod 5 equals 0, print "BZ"
6. Otherwise:
   - Calculate X = N × 2
   - Calculate S = N + X
   - Print S
7. Stop
