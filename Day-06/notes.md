# 1. Array

An array is a linear data structure used to store multiple elements.

In traditional array implementations, elements are generally of the same data type and stored in contiguous memory locations.

Each element can be accessed using its index.

### Important Points

- Array indexing starts from `0`.
- The first element is at index `0`.
- The second element is at index `1`.
- The last element is at index `n - 1`.
- Accessing an element using its index is an important advantage of arrays.

### Example

```text
Array = [10, 20, 30, 40]

Index =  0   1   2   3
Value = 10  20  30  40
