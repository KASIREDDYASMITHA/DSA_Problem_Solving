
# DSA Day 64 - Dynamic Programming - 3

7. Recursion and Memoization in House Robber

## Problems Practiced

### 1. Minimum Cost Climbing Stairs

- Find the minimum cost to reach the top of the staircase.
- We can start from stair 0 or stair 1.
- We can climb either one step or two steps.
- Applied recursion, memoization, tabulation and space optimization.

### 2. House Robber

- Find the maximum money that can be robbed.
- Two adjacent houses cannot be robbed.
- Applied recursion and memoization.

## Key Concepts

- Recurrence Relations
- Base Cases
- Overlapping Subproblems
- Memoization
- Tabulation
- Space Optimization
