# DSA Day 59 - Backtracking (Part 7)

## Topics Covered
- Letter Combinations of a Phone Number
- Word Search in a Character Grid
- Recursion and Backtracking

## Programs
1. `letter_combinations.py` - Generates all possible letter combinations for a given digit string.
2. `word_search.py` - Checks whether a word exists in a 2D character grid using adjacent cells.

## Key Concepts
- Recursion
- Backtracking
- Digit-to-letter mapping
- Grid traversal
- Visited-cell tracking

## Complexity
- Letter Combinations: O(k × 4^n) time in the worst case, where n is the number of digits and k is the length of each combination.
- Word Search: O(R × C × 4^L) time in the worst case, where R and C are the grid dimensions and L is the word length.
