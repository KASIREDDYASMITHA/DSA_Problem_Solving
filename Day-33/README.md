4. Ceil of a Number

6. Last Occurrence of an Element
7. Count Occurrences of an Element

## Description

Day 33 focuses on Binary Search problems involving
sorted arrays.

The session covers finding the lower bound, floor,
and ceil of a target element.

It also covers finding the first and last occurrences
of an element and calculating the total number of
occurrences in a sorted array.

## Complexity

| Problem | Time Complexity | Space Complexity |
|---|---|---|
| Linear Lower Bound | O(n) | O(1) |
| Binary Lower Bound | O(log n) | O(1) |
| Floor | O(log n) | O(1) |
| Ceil | O(log n) | O(1) |
| First Occurrence | O(log n) | O(1) |
| Last Occurrence | O(log n) | O(1) |
| Count Occurrences | O(log n) | O(1) |
