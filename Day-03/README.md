# DSA Day 3 - Loops 2

## Topics Covered

- Prime Number
- Prime Number using Brute Force
- Prime Number using Square Root Optimization
- Perfect Number
- Perfect Number using Divisor Pairs
- Armstrong Number
- Time and Space Complexity

## Programs

### 1. Prime Number
- `prime_number.py`
- Checks whether a given number is prime.
- Includes brute-force and optimized approaches.

### 2. Perfect Number
- `perfect_number.py`
- Checks whether the sum of proper divisors equals the number.
- Includes brute-force and optimized approaches.

### 3. Armstrong Number
- `armstrong_number.py`
- Checks whether a number is an Armstrong number.

## Key Learnings

- Using loops for number-based problems
- Finding divisors
- Optimizing divisor checks using square root
- Extracting digits using `% 10`
- Removing digits using `// 10`
- Comparing time complexities of different approaches
