# Day 28 - Monotonic Stack

## Topics Covered

* Monotonic Stack
* Nearest Greater Element to the Left
* Nearest Smaller Element to the Left
* Nearest Greater Element to the Right
* Stock Span Problem

## Concepts Learned

* Using a stack to solve array problems efficiently.
* Maintaining increasing and decreasing monotonic stacks.
* Finding the nearest greater or smaller element.
* Traversing arrays from left to right and right to left.
* Applying monotonic stacks to calculate stock spans.

## Programs

1. Nearest Greater Element to the Left
2. Nearest Smaller Element to the Left
3. Nearest Greater Element to the Right
4. Stock Span Problem

## Approach

All four problems are solved using a stack.

The stack helps eliminate unnecessary comparisons by removing elements that cannot be answers for future elements.

## Complexity

* Time Complexity: O(n) for each program.
* Space Complexity: O(n) for each program.

Here, n is the number of elements in the array.

## Key Learning

A monotonic stack maintains elements in increasing or decreasing order. It helps solve nearest greater and smaller element problems efficiently.
