## Problems Practiced

### 1. House Robber II
- Houses are arranged in a circle.
- First and last houses are adjacent.
- Convert the circular problem into two House Robber I cases.
- Exclude the last house in Case 1.
- Exclude the first house in Case 2.
- Find the maximum amount using take and skip choices.

### 2. Delete and Earn
- Calculate points for each number.
- Create a points array of size max(nums) + 1.
- Add each number to its corresponding index.
- Understand how selecting adjacent values affects the problem.
