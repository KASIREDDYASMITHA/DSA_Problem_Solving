
# DSA Day 53 - Backtracking 1

## Topics Covered
- Introduction to Backtracking
- Generate, Check and Validate approach
- General Backtracking Template
- Substrings vs Subsequences
- Generating Subsequences using Recursion
- N-Queens Problem: Basic Introduction

## Key Concepts
- Backtracking explores possible choices and returns to an earlier state when needed.
- A state represents the current situation of the problem during recursion.
- A subsequence is formed by taking or skipping each character while preserving order.
- A substring contains consecutive characters from the original string.
- N-Queens places queens on a chessboard so that no two queens attack each other.
