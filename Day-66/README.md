
# Day 66 - Dynamic Programming - 5

## Topics Covered

Today I learned the 0/1 Knapsack Problem using Dynamic Programming.

### Concepts

1. 0/1 Knapsack using Recursion
2. 0/1 Knapsack using Memoization (Top-Down DP)
3. 0/1 Knapsack using Tabulation (Bottom-Up DP)
4. DP Table Initialization
5. State Transitions

## Problem

Given a set of items, each having a weight and profit, and a knapsack with a fixed capacity, find the maximum profit without exceeding the capacity.

Each item can either be selected once or not selected.

## Approaches

- Recursion
- Memoization
- Tabulation
