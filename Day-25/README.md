# Day 25 - 2D Matrix Problems

## Topics Covered

Today I learned three important 2D matrix problems:

1. Search in a Row-wise and Column-wise Sorted Matrix
2. Rotate Matrix 90 Degrees Clockwise
3. Set Matrix Zeroes using Marker Matrix

## Approaches

- Sorted Matrix Search: Staircase Search
- Matrix Rotation: Transpose + Reverse Each Row
- Set Matrix Zeroes: Marker Matrix

## Key Concepts

- Working with rows and columns
- Traversing a 2D matrix
- Using a sorted matrix property to reduce unnecessary searches
- Matrix transpose
- Reversing rows
- Using an extra matrix to mark rows and columns
